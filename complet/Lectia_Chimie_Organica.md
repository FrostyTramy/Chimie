## 1. Tipuri de atomi de carbon

**Criteriu:** după numărul de covalențe pe care le realizează un atom de carbon cu alți atomi de carbon (nu cu atomi ai altor elemente).

| Tip | Covalențe cu alt C | Covalențe cu alte elemente | Exemplu |
|---|---|---|---|
| Nular | 0 | 4 | CH₄ (metan) |
| Primar | 1 | 3 | CH₃–CH₃ (etan) |
| Secundar | 2 | 2 | CH₃–CH₂–CH₃ (propan) |
| Terțiar | 3 | 1 | 2-metilbutan (izopentan) |
| Cuaternar | 4 | 0 | HC≡C–C(CH₃)₃ (3,3-dimetilbut-1-ină), C₆H₁₀ |

**Observație:** la legăturile multiple se numără atomii de carbon vecini, nu legăturile. De exemplu, în HC≡C–, atomul C din stânga are un singur vecin de carbon, deci este primar.

### 1.1 Atomi de C nulari
Toate cele 4 covalențe se realizează cu atomi ai altor elemente.

```
        H
        |
    H – C – H
        |
        H
```
Ex.: metanul, CH₄.

### 1.2 Atomi de C primari
O covalență se realizează cu un alt atom de carbon, celelalte 3 cu atomi ai altor elemente.

```
    H     H
    |     |
H – C  –  C – H
    |     |
    H     H
```
Ex.: etanul, CH₃–CH₃. Fiecare atom de C este primar.

### 1.3 Atomi de C secundari
2 covalențe sunt realizate cu alți atomi de C, celelalte 2 cu atomi ai altor elemente.

```
    H     H     H
    |     |     |
H – C  –  C  –  C – H
    |     |     |
    H     H     H
```
Ex.: propanul, CH₃–CH₂–CH₃. Atomul din mijloc este secundar.

### 1.4 Atomi de C terțiari
3 covalențe sunt realizate cu alți atomi de C, a patra cu un atom al altui element.

```
        H
        |
H₃C – C* – CH₂ – CH₃
        |
       CH₃
```
Ex.: 2-metilbutanul. Atomul marcat cu * (C2) este terțiar: are 3 vecini de carbon (C1, C3 și ramificația CH₃) și un H.

### 1.5 Atomi de C cuaternari
Toate cele 4 covalențe sunt realizate cu alți atomi de C.

```
              CH₃
               |
H – C ≡ C – C – CH₃
               |
              CH₃
```
Ex.: HC≡C–C(CH₃)₃, 3,3-dimetilbut-1-ină, C₆H₁₀. Atomul central (C3) are 4 vecini de carbon.

## 2. Formulele compușilor organici

### 2.1 Formula moleculară
Indică **tipul atomilor** din moleculă și **numărul lor exact**.
Ex.: C₈H₁₂, C₆H₁₀, C₁₀H₈.

### 2.2 Formula structurală
Indică **aranjarea spațială** a atomilor în moleculă.

#### a) Formula structurală plană cu linii de valență
Indică aranjarea atomilor în moleculă, cu reprezentarea **tuturor liniilor de valență** (toate legăturile, inclusiv C–H).

Ex. (3-metilpent-1-ină, C₆H₁₀):

```
            H   H   H
            |   |   |
H – C ≡ C – C – C – C – H
            |   |   |
           CH₃  H   H
```

#### b) Formula de poziție plană rezumată
Indică **succesiunea atomilor** în moleculă și **natura legăturilor covalente** dintre atomii de carbon. Legăturile C–H nu se mai desenează, iar ramificațiile se scriu sub atomul de carbon respectiv.

Ex. (din caiet):

```
CH ≡ C – CH – CH₂ – CH₃
           |
          CH₃
```
Formula de poziție: CH≡C–CH(CH₃)–CH₂–CH₃, 3-metilpent-1-ină, C₆H₁₀.

## 3. Aplicație: scheletul unei catene

**Se dă scheletul catenei:**

```
      C
      |
C ≡ C – C – C = C – C
    |
    C
```

**Se cere:**
- a) completați cu H valențele libere ale atomilor de C din catenă;
- b) precizați tipul catenei;
- c) precizați tipul atomilor de C din moleculă;
- d) scrieți formula rezumată și formula moleculară pentru hidrocarbura obținută.

### Rezolvare

**a) Completarea cu H**

Numerotăm atomii de C din lanțul principal (C1–C6) și ramificațiile (CH₃):

```
         CH₃ (la C4)
         |
H–C≡C–CH–C=CH–CH₃
      |
     CH₃ (la C3)
```
Atomii cu valențe libere, completați:
- C1 (≡C–H): 1 H;
- C2 (din tripla legătură): nimic, are deja 4 covalențe;
- C3: 1 H și o ramificație CH₃ dedesubt;
- C4: ramificație CH₃ deasupra (fără H);
- C5 (=CH–): 1 H;
- C6: CH₃, 3 H.

Total H: 1 + 1 + 3 + 3 + 1 + 3 = 12, deci C₈H₁₂.

**b) Tipul catenei**
- aciclică (deschisă), pentru că nu formează cicluri;
- ramificată, pentru că are ramificații CH₃ la C3 și C4;
- nesaturată, pentru că are o legătură triplă (C1≡C2) și o legătură dublă (C4=C5);
- hidrocarbonată, pentru că conține doar C și H.

**c) Tipul atomilor de C**

| Atom | Vecini de C | Tip |
|---|---|---|
| C1 (HC≡) | 1 (C2) | primar |
| C2 (≡C–) | 2 (C1, C3) | secundar |
| C3 (–CH<) | 3 (C2, C4, CH₃) | terțiar |
| C4 (=C<) | 3 (C3, C5, CH₃) | terțiar |
| C5 (=CH–) | 2 (C4, C6) | secundar |
| C6 (CH₃) | 1 (C5) | primar |
| CH₃ ramificație la C3 | 1 (C3) | primar |
| CH₃ ramificație la C4 | 1 (C4) | primar |

Rezumat: 4 atomi primari, 2 secundari, 2 terțiari, 0 cuaternari, 0 nulari.

**d) Formula rezumată și formula moleculară**

Formula rezumată: HC≡C–CH(CH₃)–C(CH₃)=CH–CH₃
Formula moleculară: **C₈H₁₂**
Denumirea hidrocarburii: **3,4-dimetilhex-4-en-1-ină**

## 4. Hidrocarburi aromatice

### 4.1 Hidrocarburi aromatice mononucleare
Conțin un singur nucleu benzenic (un ciclu cu 6 atomi de carbon și legături duble alternante).

Ex.: benzenul, C₆H₆.

### 4.2 Hidrocarburi aromatice polinucleare
Conțin mai multe nuclee benzenice.

**a) Cu inele condensate:** două sau mai multe inele au în comun câte o latură (2 atomi de C).

Ex.: naftalina, C₁₀H₈.

```
      ___
  ___/   \___
 /   \___/   \
 \___/   \___/
     \___/
```

**b) Cu inele izolate:** inelele benzenice sunt legate între ele printr-o legătură simplă sau printr-un atom/grupare.

Ex.: bifenilul, C₁₂H₁₀ (două inele benzenice unite printr-o legătură simplă).

```
   ___          ___
  /   \        /   \
 |     |——————|     |
  \___/        \___/
```

## 5. Completări (informații suplimentare, nu din caiet)

**Clasificarea catenelor de atomi de carbon**
- după forma lanțului: **aciclice** (deschise, fără cicluri) sau **ciclice** (închise);
- după tipul legăturilor: **saturate** (doar legături simple) sau **nesaturate** (cu legături duble și/sau triple);
- după ramificare: **normale** (neramificate) sau **ramificate**.

**Regula generală pentru tipul atomului de C**
Se numără câți atomi de C sunt legați direct de atomul respectiv, indiferent de multiplicitatea legăturii:
- 0 vecini de C → nular;
- 1 vecin → primar;
- 2 vecini → secundar;
- 3 vecini → terțiar;
- 4 vecini → cuaternar.

**Formula generală a alcanilor (saturați):** CₙH₂ₙ₊₂.
