# 2. Formulele compusilor organici

## Formula moleculara
Indica tipul atomilor din molecula si numarul lor exact.
Ex: C8H12, C6H10, C10H8.

## Formula structurala
Indica aranjarea spatiala a atomilor in molecula.

### a) Formula structurala plana cu linii de valenta
Arata toate legaturile, inclusiv cele C-H.
Ex: 3-metilpent-1-ina, C6H10

```
            H   H   H
            |   |   |
H - C#C - C - C - C - H
            |   |   |
           CH3  H   H
```

### b) Formula de pozitie plana rezumata
Indica succesiunea atomilor si natura legaturilor dintre atomii de C. Legaturile C-H nu se mai deseneaza.
Ex: CH#C-CH(CH3)-CH2-CH3, 3-metilpent-1-ina.

```
CH # C - CH - CH2 - CH3
           |
          CH3
```
