# 1. Tipuri de atomi de carbon

Criteriu: numarul de covalente pe care un atom de C le realizeaza cu alti atomi de C.

- Nular: 0 covalente cu C, 4 cu alte elemente. Ex: CH4 (metan)
- Primar: 1 cu C, 3 cu alte elemente. Ex: etan
- Secundar: 2 cu C, 2 cu alte elemente. Ex: propan
- Terțiar: 3 cu C, 1 cu alt element. Ex: 2-metilbutan
- Cuaternar: 4 cu C, 0 cu alte elemente. Ex: 3,3-dimetilbut-1-ina, C6H10

Observatie: la legaturile multiple se numara atomii vecini de C, nu legaturile.

## Nular (metan)

```
        H
        |
    H - C - H
        |
        H
```

## Primar (etan)

```
    H     H
    |     |
H - C  -  C - H
    |     |
    H     H
```

## Secundar (propan)

```
    H     H     H
    |     |     |
H - C  -  C  -  C - H
    |     |     |
    H     H     H
```

## Terțiar (2-metilbutan)

```
        H
        |
H3C - C* - CH2 - CH3
        |
       CH3
```
C* (C2) are 3 vecini de C: C1, C3 si ramificatia CH3.

## Cuaternar (3,3-dimetilbut-1-ina, C6H10)

```
              CH3
               |
H - C#C - C - CH3
               |
              CH3
```
Atomul central are 4 vecini de C.
