# Toate desenele

## Sectiunea 1: Tipuri de atomi de carbon

### 1. Atom de C nular (metan)
Sectiune: Tipuri de atomi de carbon > Nular

```
        H
        |
    H - C - H
        |
        H
```

### 2. Atom de C primar (etan)
Sectiune: Tipuri de atomi de carbon > Primar

```
    H     H
    |     |
H - C  -  C - H
    |     |
    H     H
```

### 3. Atom de C secundar (propan)
Sectiune: Tipuri de atomi de carbon > Secundar

```
    H     H     H
    |     |     |
H - C  -  C  -  C - H
    |     |     |
    H     H     H
```

### 4. Atom de C terțiar (2-metilbutan)
Sectiune: Tipuri de atomi de carbon > Terțiar

```
        H
        |
H3C - C* - CH2 - CH3
        |
       CH3
```

### 5. Atom de C cuaternar (3,3-dimetilbut-1-ina, C6H10)
Sectiune: Tipuri de atomi de carbon > Cuaternar

```
              CH3
               |
H - C#C - C - CH3
               |
              CH3
```

## Sectiunea 2: Formulele compusilor organici

### 6. Formula structurala plana cu linii de valenta (3-metilpent-1-ina)
Sectiune: Formule > Formula structurala > a) cu linii de valenta

```
            H   H   H
            |   |   |
H - C#C - C - C - C - H
            |   |   |
           CH3  H   H
```

### 7. Formula de pozitie plana rezumata (3-metilpent-1-ina)
Sectiune: Formule > Formula structurala > b) de pozitie plana rezumata

```
CH # C - CH - CH2 - CH3
           |
          CH3
```

## Sectiunea 3: Aplicatie cu scheletul catenei

### 8. Scheletul catenei (se da)

      |
C#C - C - C = C - C

    C

         CH3 (la C4)

H-C#C-CH-C=CH-CH3
